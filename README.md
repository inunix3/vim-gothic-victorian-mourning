# Gothic Victorian Mourning for Vim

Elegant gothic colorscheme for Vim. Basically it's port of the Gothic Victorian Mourning from [Midnight Coven: Gothic Theme Collection](https://marketplace.visualstudio.com/items?itemName=Diyllan.midnight-coven-themes) extension for VSCode. This particular theme I liked the most, so I've
decided to port it to Vim.

I've made it for myself, so it will be updated mainly when I spot that some
colors are off. Issues or pull requests are welcome, of course.

**GVim or TrueColor terminal is required.**

## Installation

Install via your plugin manager the same way as you would install any other
plugin or colorscheme, or manually by copying `colors` and `autoload` folders into
your .vim/ directory.
